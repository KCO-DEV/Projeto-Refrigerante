# 🥤 Projeto Refrigerante

Aplicação desenvolvida com foco em prática de desenvolvimento web, organização de código e versionamento com Git/GitHub.

O projeto simula uma página/sistema relacionado a refrigerantes, com objetivo de treinar conceitos de interface, estrutura de pastas e boas práticas de programação.

---

## 🚀 Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Git & GitHub
